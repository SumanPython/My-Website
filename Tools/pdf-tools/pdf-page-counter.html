Check PDF Page Count and Paper Size Online

Need to know how many pages a PDF contains before printing, submitting, or sharing it? The PDF Page Counter & Page Size Checker from Online Tool Collection helps you inspect a document in a few seconds. Choose a PDF file to see the total number of pages, the size of the file, and the dimensions of its pages. You can check whether a document uses A4, A3, Letter, Legal, or a custom paper size without opening a desktop PDF application.

This tool is useful when preparing documents for printing or when a website, application, school, office, or application form specifies page requirements. It reports each page separately, so you can spot a PDF that contains a mixture of paper sizes. Page orientation is shown as portrait or landscape, making it easier to identify pages that may need review before printing or sharing.

PDF page dimensions are displayed in points and converted to millimeters and inches for convenient reference. The paper-size label is based on the measured page dimensions and is intended as a helpful identification, not a guarantee of printer settings. Custom-sized pages are shown with their actual dimensions instead of being forced into a standard paper label.

Using the checker is straightforward: select or drop your PDF into the tool, wait for the document to be read, and review the results. No account or installation is required. Processing happens locally in your browser, so the selected file is not sent to Online Tool Collection. For very large PDFs, processing may take longer and use more memory on your device. The checker reads document information only; it does not edit, compress, or change your original PDF. You can keep your original file unchanged and use the page details to decide what to do next.

Frequently Asked Questions

How can I check the page count of a PDF?

Select or drop your PDF into the checker. Once the document is read, the total number of pages is displayed in the results summary.

Can this tool identify A4, Letter, and other paper sizes?

Yes. It compares each page's measured dimensions with common paper sizes, including A4, A3, A5, A6, Letter, Legal, and Tabloid. Pages that do not match are labeled Custom.

Can a PDF contain pages with different sizes?

Yes. The checker reports each page separately, so documents containing a mixture of paper sizes or orientations can be identified.

Are my PDF files uploaded to a server?

No. The PDF is processed locally in your browser using PDF.js. The file is not sent to Online Tool Collection, and the tool does not modify your original document.
