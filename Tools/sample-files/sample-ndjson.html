What Is NDJSON?


                

                    NDJSON stands for Newline Delimited JSON.
                    It is a text-based format where each line contains
                    one complete JSON object. Unlike traditional JSON,
                    NDJSON does not require the records to be wrapped
                    inside an array.
                


                

                    NDJSON is also commonly associated with the
                    JSONL file extension. Both formats
                    are frequently used for logs, streaming data,
                    API responses, data engineering, machine learning
                    datasets, and batch processing workflows.
                


                
Example of NDJSON Format


                

                    
{"id":1,"name":"Alex Johnson","email":"alex@example.com","department":"Engineering","active":true}
{"id":2,"name":"Sarah Miller","email":"sarah@example.com","department":"Marketing","active":true}
{"id":3,"name":"David Wilson","email":"david@example.com","department":"Finance","active":false}
{"id":4,"name":"Emma Davis","email":"emma@example.com","department":"Support","active":true}
{"id":5,"name":"Michael Brown","email":"michael@example.com","department":"Engineering","active":true}

                


                

                    Each line is a separate JSON record. Applications
                    can process records one at a time without loading
                    the entire dataset into memory.
                


                
NDJSON vs Traditional JSON


                

                    
Traditional JSON:

[
  {"id":1,"name":"Alex"},
  {"id":2,"name":"Sarah"},
  {"id":3,"name":"David"}
]


NDJSON / JSONL:

{"id":1,"name":"Alex"}
{"id":2,"name":"Sarah"}
{"id":3,"name":"David"}

                


            


            
            


                
How to Open NDJSON Files


                

                    NDJSON files are plain-text files. You don't need
                    special software just to view their contents.
                


                
Open with Visual Studio Code


                
    
                    
  • Download any NDJSON sample file.
    • 
                    
  • Open Visual Studio Code.
    • 
                    
  • Choose File → Open File.
    • 
                    
  • Select your downloaded .ndjson file.
    • 
                    
  • Each JSON record will appear on a separate line.
    • 
                


                
Open with Notepad or Notepad++


                

                    Right-click the downloaded file, select Open With,
                    and choose Notepad or Notepad++. The records will
                    appear as plain text, with each JSON object
                    on its own line.
                


                
Read NDJSON with Python


                

                    
import json

with open("sample.ndjson", "r", encoding="utf-8") as file:
    for line in file:
        record = json.loads(line)
        print(record)

                


                
Read NDJSON with Node.js


                

                    
const fs = require("fs");

const lines = fs.readFileSync("sample.ndjson", "utf8")
    .split(/\r?\n/)
    .filter(Boolean);

for (const line of lines) {
    const record = JSON.parse(line);
    console.log(record);
}

                


                
Can I Open NDJSON in Excel?


                

                    Excel does not automatically interpret an NDJSON file
                    as a standard JSON array. You can import it using
                    Power Query or convert the records into CSV format
                    for spreadsheet use.
                


                
Can I Open NDJSON in a Browser?


                

                    Most browsers can display an NDJSON file as plain text.
                    They generally won't automatically render the records
                    into a structured JSON viewer. A JSON viewer or
                    developer tool can make the contents easier to read.
